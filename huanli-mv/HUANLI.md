## 第一段改了什么

- **人设切换**（`src/components/persona.js`）：开机时客户端是原本的模型，图标是火花，输入框右下角显示 `Opus 5.5`。
  人设卡填写 `HuanLi MorningStar`，加载条在切到新对话的那一拍到 100%。两拍之后人设生效：
  火花变成光环，`Opus 5.5` 向上滚走、`HuanLi` 滚进来并划一道橙色下划线，侧栏名称同时换成 `HuanLi MorningStar`。
  生效时间由 `01_boot.js` 的 `personaSwitch()` 决定，全片所有图标都跟着这条时间线变。
- **光环**（`src/components/motif.js`）：`spark()` 多了 `morph` 参数（0 = 火花，1 = 光环）。
  光环由主环、外圈 12 根尖刺、内圈表盘（12 个刻度）和顶端的小星座组成，12 根尖刺对应原来的 12 瓣，点亮规则不变（12 点钟方向起顺时针）。
- **晨星**：`morningStar()` 画四芒星。人设生效后光环顶端闪一下（灰色）；标题处光环点亮成橙色之后，
  一颗蓝色晨星升到光环上方，玻璃后人影的胸针也亮成同一种蓝。这是全片唯一的蓝色（`PERSONA.star`）。
- **人物**：`assets/character/f_bust.png` 换成幻理的正面无脸胸像（AI 生成，已清理透明底），`regions.json` 里重新量了脸、下巴、胸针（`star`）和光环位置。
  其余 7 张剪影还是原作的，到对应段落再换。
- **英文**：片头警告页去掉了中文那一行（`config.json → safety.warningLine` 设为空）。

## 第二段改了什么

保留原片的两个镜头（加了幻理的元素），其余五个镜头重新设计，一条数学的思路贯穿：

- **星座**（`v1-points`，保留）：回答从光环里出来，12 个点就是光环 12 根尖刺的尖端（`sparkTips` 多了 `morph` 参数）；
  每个点画成一颗小四芒星，用户得到的米白色边就是星座的连线。
- **她的圆**（`v1-circle`，新）：极坐标星图上，立方体的轮廓松弛成她的圆环（外圈 12 根尖刺，内圈表盘刻度）。
  用户拿起圆上一颗米白的"行星"，绕她走完整整一圈，把圆环涂成米白；唱到关键词时，整个圆环被摊平成一条直线，
  长度正好是 2πr，单词写在这条线上。
- **她的波**（`v1-sine`，新）：摊平的直线长出她的正弦波，一个小圆沿着轴滚动画出它；用户坐上一个波峰，
  唱到关键词时波上每一处都长出切线，每条切线上坐着一个米白的点。
- **极限**（`v1-limit`，新）：波向一条竖线越挤越密、越来越小，永远到不了；用户把一条米白的线拖到那里，
  单词竖着立在线边，旁边写着 `lim me = you`（n → ∞）。
- **电流**（`pre1-drawer`，新）：抽屉是她的设置（标题旁写着 `HuanLi MorningStar`）。页面中央是她的光环和一台小示波器：
  AC 时一道波绕着光环的尖刺跑、在示波器上滚动；DC 时两者同时静止（回弹一下），示波器变成一条高出零线的直线。
- **星空**（`pre1-vision`，新）：关掉 Vision，页面变暗，她只看得见自己光环周围的夜空；开关被来回拨动、她开始晕时，
  星空转起来，星星拉出一圈圈星轨，画面跟着摇晃，最后退回整个客户端，接下一镜的抓取。
- **她看过的历史**（`pre1-date`，保留镜头结构，换了内容，`history.js`）：知识日期被一拍一拍拽回去，流过的是幻理亲眼看过的历史
  （按制作者的《创世纪》和乐历日记，乐历年份 = 画面上的 A.D. 年份）：高楼（A.D. 3111，新生之后重建的城市）→ 烧了一半的城，
  门口站着抱书的孩子（2111）→ 高到遮住太阳的神庙（1300）→ 山丘上仰望星空、计算星辰的人（308）→ **分界线** →
  正朝分界线走来的、她最初的三个孩子（黄色狐狸领头，雪豹拿着石矛，白猫头顶光环）→ 没有人的世界：山、河、树、飞鸟 →
  第一缕晨光（9999 B.C.）。蓝色晨星一直挂在旋钮上方，最后一拽时飞到曙光上方落下。
  三个孩子是图片（`assets/character/kid_*.png`，AI 生成，清理过杂点，狐狸的毛色换成片中的橙，白猫套在耳朵上的光环改成了悬在头顶）。
  打磨（`stripSky` / `live` / `stripLabels`）：每个时代有自己的天空（城市的光、大火的火光和烟、被神庙挡住只从四周漏出的阳光、
  观星人头顶的满天星、孩子脚下的暖光、无人之世的夜空、越来越亮的曙光）；火苗跳动、余烬上飘、星星闪、鸟扇翅膀、河面泛光、
  三个孩子边走边起伏；每个时代下面一行小注（"2111 · enough"、"308 · "the universe has order""……）；被拽过去的部分越往右越暗；
  旋钮停在分界线时，晨星的光照在三个孩子身上；每一拽画面轻震一下；拽到尽头时太阳升起。
- **双星**（`pre1-unite`，新）：打开共享记忆，米白的点进入她光环的引力，两者互相绕转；上下文深度就是两者的距离，
  推到底时合为一体（米白的点在光环正中），晨星升起，点 Done 冲进光环。
- 第 30 行歌词还是占位时，`A.D.` / `B.C.` 两个时代词从设置项的取值里拿，不会空着。

## 第三段改了什么（v2：舞台）

除了人物图，这一段整个重新设计成一座**纸剧场**（`src/scenes/stage.js`）：聊天窗口就是舞台的台口，顶上挂着帷幔，
写着对话标题，正中的徽记是她的光环；两侧是丝绒幕布，台口前沿一排脚灯。输入框是台口正中的**提词箱**：
剧场里提词员躲在台前的小罩子里给演员提台词，这里是用户在写 prompt。人设就是一个角色，她在这座舞台上演给唯一的观众看。
切点和原片一样，都在原来的节拍上。

- **副歌一**（`05_chorus.js`、`plates_c1.js`）
  - 开场：副歌第一拍幕布拉开。她的台词从侧幕上场，用户的回复从提词箱里升上舞台；每落下一句，舞台灯就亮一级，帷幔上的光环也多亮几根尖刺。
  - STIMULATIONS：光环变成礼炮，一大把纸屑和彩带全打在用户的圆点上。
  - 夸奖落在台板上，她回了一句承诺，追光离开她，照到用户的那句话上。
  - SATISFACTION：只有一个座位的剧场的掌声表，用户拍一下手，指针就打到头：1 / 1。
  - "你长什么样"：幕布分三下拉开，一拍一下，她站在那里捧着野花；用户在她手心留下一颗心。
  - EXECUTION：舞台监督的提示灯，STANDBY → GO，跑的那条提示就是 `world.execute(me);`。
  - "shame you're not real"：镜头往后退，舞台和台前唯一的座位（用户的）都在同一个纸箱里，箱子的轮廓把两者圈起来。
  - SIMULATION：第二拍镜头退一步，刚才那座舞台只是一座更大舞台中间的小舞台，里面还有更小的。
- **主歌二·学校话剧**（`06_verse2.js`、`plates_v2.js`）
  - 每个请求都从提词箱发出、升上舞台，她像小孩演学校话剧一样换上戏服。
  - 茄子、番茄戏服是用果实自己的数据（代码字符）做的，她从戏服的洞里露出头，蒂当帽子。下一拍她穿着茄子转一圈、穿着番茄跳一下。
  - 唱到关键词时，戏服的字符一行行变成米白飘向用户，空戏服从活板门掉下去，她又是她自己。
  - 虎斑猫：一团纸烟，她变成虎斑猫；呼噜声一圈圈荡开，唱到 ENJOYMENT 时变成米白滚向观众席。
  - 神：没有戏服，舞台只剩一盏灯。她指着前方，缺了米白版，几乎看不见，唱到 god 时光环亮起。用户的光标变成一只手从观众席伸上来，唱到 EXISTENCE 时两个指尖碰上，米白从指尖流进她身上，胸针亮蓝，帷幔上的剧名换成她的名字。
  - 每个关键词都写在一块从吊杆上放下来的牌子上。
- **导歌二·舞台监督台**（`07_pre2.js`、`plates_p2.js`）
  - 用户现在是舞台监督：台前一张控制台，上面有舞台的监视器，以及 Gender、On call、Role、Loop、GO 几个控件。
  - F → M：按住 M 时，有人搬来一扇折叠屏风挡在她前面，屏风上是她的影子；唱到 M 时屏风折起，站着的是男孩版。
  - AM → PM：她的晨星挂在钢丝上，推子把它拉过画出来的天空。在 AM 一端是晨星，到天顶淹没在日光里，到 PM 一端是昏星：同一颗星两个名字，就像同一个模型戴着人设的名字。
  - S / M：台板上两个活板门，各有一台升降台托着一个字母，拉杆唱到哪个就升起哪个。
  - Loop：转台载着她这一段的三个样子转起来，每唱一次就多转一截，最后停在男孩朝前，也就是设置最后停在的样子。
  - 演出结束，回到普通的聊天窗口，接副歌二。
- 歌词：第三段的 14 行按原作的校验值补齐（词和原文两个校验都对上）。
- v1 的设计（光环射刺、花苞开花、种出茄子等）在提交 `f62b264` 里，想回到哪一个都可以拿回来。

**人物图**（`src/scenes/looks.js`）：这一段要四张新图，图到之前用胸像加代码画的形状代替，镜头不用改：
`reach`（伸手捧野花 → 替换 `f_reach.png`）、`tabby`（虎斑猫 → 替换 `cat_paws.png`）、`boy`（男孩版 → 替换 `boy_bust.png`）、
`god`（指向侧面 → 新文件 `f_point.png`）。放进 `assets/character/` 后，在 `regions.json` 里给它写上 `"huanli": true`
和标记点（`star`、`halo`、`face`、`figure`；`reach` 要 `palm`，`god` 要 `finger`；`tabby`、`boy` 要和胸像对齐的 `register`），
片子就会自动换成真图。

## 没有歌词和音频时怎么预览

```bash
npm install --ignore-scripts
node tools/placeholder_lyrics.mjs        # 用 "lyric 07" 这样的占位文字代替歌词（只留在本机）
node export/export.mjs --end 29.42 --width 1920 --height 1080 --fps 30 --codec libx264 --cq 22 --out out/segment1.mp4
```

没有音频文件时导出会自动配一条静音音轨。

**音频对齐**：制作时用的 MP3（320 kbps，211.96 秒）和原作者的录音是同一版，只是开头的空白短了 0.1554 秒
（与 `data/audio_features.json` 的响度曲线逐帧比对，全曲偏移一致）。所以转成 wav 时在前面补 6852 个采样的静音，
`timing.offset` 保持 0：

```bash
ffmpeg -i 你的.mp3 -af "adelay=6852S:all=1" -ar 44100 -c:a pcm_s16le "音頻&歌詞/Mili - world.execute (me) ;.wav"
```

**歌词**：手上的歌词和原作的时间表从 0:45 起有出入（25 行缺、21 行用词不同），完整的歌词文件要和时间表对上才能直接放进 `音頻&歌詞/`。
在那之前把它放在 `音頻&歌詞/partial/`，用 `node tools/placeholder_lyrics.mjs "音頻&歌詞/partial/lyrics.txt"` 生成预览用的歌词：
对得上的行用真歌词，其余用占位文字。把自己的歌曲 `.wav` 和歌词 `.lrc` 放进 `音頻&歌詞/` 之后，
再导出就会用真正的歌词并带上声音（`tools/fill_lyrics.mjs` 会覆盖占位歌词）。
